# Neon Portfolio

A neon-themed freelance developer portfolio: interactive particle background, glitch and typewriter hero, 3D tilt project cards, magnetic buttons and scroll animations.

**Stack:** Vite · React 19 · TypeScript · Tailwind CSS v4 · Motion

## Run locally

```bash
npm install
npm run dev
```

## Make it yours

All content (name, links, services, projects, stats, testimonials) lives in `src/data/profile.ts`.

## Deploy

Every push to `main` builds the site and publishes it to GitHub Pages via `.github/workflows/deploy.yml`.
